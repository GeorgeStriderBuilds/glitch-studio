# Glitch Studio

A single-file, browser-based photo editor for glitch art. Open `index.html` in a browser — no build step, no server needed.

## What it does

Upload a photo, then experiment with glitch effects:

- **Mirror** — mirrored reflections
- **Kaleidoscope** — mirrored kaleidoscope patterns
- **Datamosh-style** — datamosh-style distortion
- **Effects** — additional glitch effects, with shuffle/randomize
- **Overlay photo** — layer a second photo over the first
- **Color** — color adjustments

You can undo, reset, compare with the original, and save the result as a PNG.

## Try it

- Open `index.html` directly in your browser, or
- Once GitHub Pages is enabled for this repo, use the published Pages URL (see the repo's Pages settings / About section)
